# 第二部分　论文阅读笔记（续）—— 目标检测

> 目标检测演进主线：two-stage（R-CNN → Fast R-CNN → Faster R-CNN → FPN）追求精度；
> one-stage（YOLO → SSD）追求速度。两条路线最终在精度-速度权衡中趋于融合。

---

### 8. Rich feature hierarchies for accurate object detection and semantic segmentation（R-CNN）

- **作者/机构**：Ross Girshick 等（UC Berkeley），2014 年，arXiv:1311.2524
- **一句话**：把 CNN 用于目标检测的开山之作：**Selective Search 生成候选框 + CNN 提特征 + SVM 分类 + 回归微调**。

**动机**：在 R-CNN 之前，目标检测由 DPM 等手工特征方法主导，性能多年停滞；CNN 在分类上已取得突破，但检测还面临"目标位置、尺寸、个数均未知"的挑战。

**核心方法**（three-step pipeline）：
1. **候选区域生成**：Selective Search 在每张图上提取约 2000 个可能包含目标的区域（region proposal）；
2. **特征提取**：把每个候选区域裁剪缩放到 $227\times227$，送入 CNN（AlexNet）得到 4096 维特征；
3. **分类与回归**：每个区域的特征分别用类别 SVM 判断"是不是目标、是哪类"；再用线性回归微调边界框位置。

**关键技巧**：预训练 + 微调（先在 ImageNet 预训练，再在检测数据上微调分类器）；使用 NMS 去重。

**实验结果**：PASCAL VOC 2010 上 mAP 从 DPM 的 33.4% 提升到 53.3%，性能翻倍级提升，定义了两阶段检测范式。

**局限**（也为后续工作留了方向）：
- 每张图 2000 个候选区域都要独立过一遍 CNN，**重复计算严重**，一张图约 47 秒，无法实时；
- 训练流程繁琐（SVM 与 CNN 特征分离，需要分阶段训练）。

**我的理解**：R-CNN 的意义是"把检测问题拆成可复用的分类问题"，用数据驱动特征替代手工特征。其性能瓶颈（重复卷积、多阶段训练）直接催生了 Fast R-CNN。

### 9. Fast R-CNN

- **作者/机构**：Ross Girshick（Microsoft Research），2015 年，arXiv:1504.08083
- **一句话**：用 **RoI Pooling** 让整图只过一次 CNN，把候选区域的特征提取从"2000 次独立卷积"合并为"1 次共享卷积"，并统一了训练流程。

**动机**：R-CNN 重复卷积太慢、多阶段训练繁琐。能否让整图只算一遍特征，候选区域共享？

**核心方法**：
1. **整图单次卷积**：整幅图过 CNN 得到整张特征图；
2. **RoI Pooling**：把每个候选区域在特征图上对应的子区域，池化为固定尺寸（如 $7\times7$），再送入全连接分支；
3. **多任务联合训练**：一个网络同时输出**分类 softmax + 边界框回归**，损失 = 分类损失 + 平滑 L1 回归损失，端到端训练，不再分阶段。

**实验结果**：训练速度较 R-CNN 快约 9 倍，推理快约 25 倍（VOC2007 测试，GPU），精度 mAP 66% 高于 R-CNN 的 66.0%——又快又好。

**我的理解**：RoI Pooling 是"共享特征 + 区域对齐"的关键设计，解决了特征复用与可变尺寸两大难题。但候选框仍由外部 Selective Search 生成，且 CPU 上很慢——"生成候选框"成为新的瓶颈，引出 Faster R-CNN。

### 10. Faster R-CNN: Towards Real-Time Object Detection with Region Proposal Networks

- **作者/机构**：Shaoqing Ren, Kaiming He, Ross Girshick, Jian Sun，2015 年，arXiv:1506.01497
- **一句话**：用**区域提议网络（RPN）**替代 Selective Search，把候选框生成也交给神经网络，实现检测全流程端到端、近实时的两阶段检测器。

**动机**：Fast R-CNN 中候选框生成（Selective Search）仍是 CPU 瓶颈。既然卷积特征已经算好，何不直接在特征图上"预测"哪些区域可能是目标？

**核心方法**：
1. **RPN（Region Proposal Network）**：在共享特征图上，用一个 $3\times3$ 滑窗 + 两个分支（分类层：是否有目标；回归层：边界框偏移），配合**锚点（anchor）**机制——在特征图每个位置预设多种尺度和长宽比的锚框（常见 3 尺度 × 3 比例 = 9 个）；
2. **锚点**是关键创新：让网络预测"预设锚框的偏移"而非绝对坐标，大幅降低回归难度；
3. **共享卷积特征**：RPN 与 Fast R-CNN 共享底层特征，两阶段联合/交替训练，端到端优化。

**实验结果**：VOC2007 mAP 73.2%，单张 GPU 推理约 0.2 秒（接近实时），比 Fast R-CNN 快 10 倍；候选框质量也更高。

**我的理解**：Faster R-CNN 使"候选框生成"学习化，anchor 机制成为现代检测器（包括 one-stage）的通用基石。至此 two-stage 路线（RPN 提框 → RoI 精修）定型，是后续 Mask R-CNN、FPN 等工作的基础。

### 11. Feature Pyramid Networks for Object Detection（FPN）

- **作者/机构**：Tsung-Yi Lin 等（Facebook AI Research），2017 年，arXiv:1612.03144
- **一句话**：构建**多尺度特征金字塔**，让每个尺度（浅层→深层）都获得强语义信息，从而同时检测大小差异很大的目标。

**动机**：目标检测中物体尺度差异巨大（小人脸 vs 整辆卡车）。深度 CNN 中**浅层特征分辨率高但语义弱**、**深层特征语义强但分辨率低**，单一顶层特征无法同时兼顾小目标与大目标。

**核心方法**（top-down + lateral connections）：
1. **自顶向下路径**：从最高层（语义最强、分辨率最低）逐层上采样，向低层传播强语义；
2. **横向连接**：每层上采样结果与对应层的自底向上特征做 $1\times1$ 卷积降维后**逐元素相加**，融合高分辨率细节与高层语义；
3. 在金字塔的每一层独立做预测（在 Faster R-CNN 上就是每层跑 RPN + RoI Pooling），小目标用浅层、大目标用深层。

**实验结果**：在 Faster R-CNN 基础上加 FPN，COCO mAP 提升约 2-3 个点；尤其**小目标（AP_S）提升显著**（+4 个点以上），成为后续检测器（RetinaNet、Mask R-CNN）的标准组件。

**我的理解**：FPN 的价值是"把天然存在的多尺度金字塔用横向连接补强语义"，用很小的参数代价换来了多尺度鲁棒性。它说明架构设计（如何组织特征）与模型容量同样重要。

### 12. You Only Look Once: Unified, Real-Time Object Detection（YOLOv1）

- **作者/机构**：Joseph Redmon 等（University of Washington），2016 年，arXiv:1506.02640
- **一句话**：把检测建模为**一次回归**：整图只看一次，直接在网格上预测边界框和类别，是 one-stage（单阶段）检测的开山之作。

**动机**：two-stage 方法（R-CNN 系列）速度不够快，难以实时。能否把"提框+分类"合并为一次前向回归，直接输出检测结果？

**核心方法**：
1. 把输入图像划分为 $S\times S$ 网格（$S=7$）；
2. **每个网格单元**负责预测 $B$ 个边界框（$B=2$），每个框输出 $(x,y,w,h,confidence)$，其中 $confidence$ 表示"框内含有目标的概率 × 框与真实框的 IoU"；
3. 每个网格同时预测 $C$ 类条件类别概率（$C=20$，VOC）；
4. 网络（24 卷积 + 2 全连接）输出维度 $S\times S\times(B\cdot5+C)$，一次前向即可得到全部检测结果；
5. 损失 = 坐标损失 + 含目标置信度损失 + 无目标置信度损失 + 分类损失，分项加权。

**实验结果**：VOC2007 上 mAP 63.4%，在 Titan X 上 **45 FPS**（快速版 155 FPS），比实时 two-stage 方法快一个量级。

**局限**：
- 每个网格只能预测 B 个框，**密集小目标易漏检**；
- 网格固定（7×7），对聚集目标表现差；
- 定位误差较大（v1 主要问题）。

**我的理解**：YOLOv1 用"分而治之 + 全局回归"实现了实时检测，其"看一眼就出结果"的思想与 two-stage 的"先看再看"形成鲜明对比。后续 YOLO 系列针对小目标与定位持续改进，演变为最流行的工业检测器。

### 13. SSD: Single Shot MultiBox Detector

- **作者/机构**：Wei Liu 等，2016 年，arXiv:1512.02325
- **一句话**：在**多个不同尺度的特征图**上做密集的锚框回归，既保持 YOLO 的单阶段速度，又显著改善小目标与定位精度。

**动机**：YOLO 速度虽快，但固定 7×7 网格漏检小目标、定位不准；Faster R-CNN 精度高但慢。SSD 想"两全其美"——one-stage 的速度 + 多尺度特征带来的精度。

**核心方法**：
1. **多尺度特征图预测**：在基础网络（VGG-16）后接若干卷积层，得到分辨率递减的特征图（38×38、19×19、10×10、5×5、3×3、1×1），在每层都做检测预测——浅层负责小目标，深层负责大目标；
2. **锚框（default boxes）**：每个位置预设多种尺度和长宽比的锚框，与 Faster R-CNN 的 anchor 类似但覆盖多尺度、多长宽比；
3. **匹配策略**：每个真实框与 IoU 最大的锚框匹配为正样本，IoU 大于阈值（0.5）的锚框也可为正样本；
4. **难例挖掘 + 数据增强**：控制正负样本比例 1:3；使用随机裁剪、缩放等增强提升鲁棒性。

**实验结果**：VOC2007 mAP **74.3%**，FPS 59（Titan X）——精度超过 Faster R-CNN（73.2%）的同时速度快近 3 倍；COCO 上也优于当时方法。

**我的理解**：SSD 融合了两条路线的优点（多尺度 + 锚框 + 单阶段），是 one-stage 检测精度首次反超 two-stage 的代表作。它证明"多尺度密集预测"是 one-stage 精度提升的关键，直接启发了 RetinaNet（FPN 版 one-stage）。

## 目标检测技术脉络总结

```
two-stage（精度优先）：
  R-CNN(2014) → Fast R-CNN(2015, RoI池化) → Faster R-CNN(2015, RPN+anchor) → FPN(2017, 多尺度金字塔)
one-stage（速度优先）：
  YOLOv1(2016, 网格回归) → SSD(2016, 多尺度锚框)
```

| 模型 | 范式 | 候选框来源 | 特征利用 | VOC2007 mAP | 速度 |
|---|---|---|---|---|---|
| R-CNN | two-stage | Selective Search | 每框独立 CNN | 66.0% | ~0.5 FPS |
| Fast R-CNN | two-stage | Selective Search | 全图共享 + RoI池化 | 70.0% | ~0.5 FPS（快25倍） |
| Faster R-CNN | two-stage | RPN（学习） | 共享特征 + anchor | 73.2% | ~5 FPS |
| YOLOv1 | one-stage | 无（网格回归） | 全局一次回归 | 63.4% | 45 FPS |
| SSD | one-stage | 锚框（多尺度） | 多尺度特征图预测 | 74.3% | 59 FPS |

> 注：速度数值随硬件与实现差异而不同，上表反映论文报告口径的数量级关系。
