## 二、学习内容总结

### 2.1 机器学习基本概念

根据《神经网络与深度学习》（邱锡鹏 第2版）**第2章"机器学习概述"**，机器学习是让计算机从数据中自动学习规律，并利用学到的规律对未知数据进行预测的方法。

#### 2.1.1 基本要素

一个完整的机器学习方法包含以下要素：

- **数据（Data）**：由样本构成，分为训练集、验证集、测试集。训练集用于学习模型参数，验证集用于模型选择与超参数调整，测试集用于最终评估泛化性能。
- **模型（Model）**：假设空间中的一个参数化函数族 $f(\boldsymbol{x}; \theta)$。模型可分为线性模型和非线性模型。
- **学习准则（Learning Criterion）**：通过损失函数 $\mathcal{L}(y, f(\boldsymbol{x}; \theta))$ 量化预测与真实标签的差异，目标是使期望风险 $\mathcal{R}(\theta) = \mathbb{E}_{(\boldsymbol{x},y) \sim p_r(\boldsymbol{x},y)}[\mathcal{L}(y, f(\boldsymbol{x}; \theta))]$ 最小化。
- **优化算法（Optimization Algorithm）**：通过梯度下降等方法最小化经验风险。
- **评价指标（Evaluation Metric）**：如准确率、精确率、召回率等。

#### 2.1.2 损失函数

常用的损失函数包括：

- **0-1 损失**：直接衡量分类是否正确，但不可导，难以优化
- **平方损失**：适用于回归任务，$\mathcal{L}(y, \hat{y}) = \frac{1}{2}(y - \hat{y})^2$
- **交叉熵损失**：适用于分类任务，$\mathcal{L}(\boldsymbol{y}, \hat{\boldsymbol{y}}) = -\sum_{c=1}^{C} y_c \log \hat{y}_c$

交叉熵损失衡量真实分布 $\boldsymbol{y}$（one-hot 向量）与模型预测分布 $\hat{\boldsymbol{y}}$ 之间的差异，当与 Softmax 函数配合使用时，梯度形式非常简洁。

#### 2.1.3 梯度下降法

梯度下降（Gradient Descent）是机器学习中最常用的优化算法。对于参数 $\theta$，其更新规则为：

$$\theta^{(t+1)} = \theta^{(t)} - \alpha \cdot \nabla_\theta \mathcal{L}$$

其中 $\alpha$ 为学习率，$\nabla_\theta \mathcal{L}$ 为损失函数对参数的梯度。梯度方向是函数值上升最快的方向，因此沿负梯度方向更新参数可使损失函数下降。

### 2.2 线性模型与神经网络的关系

**第3章"线性模型"** 介绍了线性分类模型的基本形式：

$$f(\boldsymbol{x}; \boldsymbol{w}) = \boldsymbol{w}^T\boldsymbol{x} + b$$

对于多分类问题，"argmax" 方式使用 $C$ 个判别函数：

$$f_c(\boldsymbol{x}; \boldsymbol{w}_c) = \boldsymbol{w}_c^T\boldsymbol{x} + b_c, \quad c \in \{1, 2, \cdots, C\}$$

预测时取得分最大的类别：$y = \arg\max_c f_c(\boldsymbol{x}; \boldsymbol{w}_c)$

**Softmax 回归** 将线性得分映射为概率分布：

$$p(y=c|\boldsymbol{x}) = \frac{\exp(\boldsymbol{w}_c^T\boldsymbol{x} + b_c)}{\sum_{c'}\exp(\boldsymbol{w}_{c'}^T\boldsymbol{x} + b_{c'})}$$

神经网络可以看作是在线性模型的基础上，引入了**非线性隐藏层**和**可学习的特征表示**。一个**人工神经元**的本质正是：先计算线性加权和 $\boldsymbol{w}^T\boldsymbol{x} + b$，再经过非线性激活函数 $h(\cdot)$。多层神经网络则将这一过程进行堆叠组合，使得模型能够学习到更加复杂的决策边界。

### 2.3 前馈神经网络

**第4章"前馈神经网络"** 系统介绍了神经网络的结构与学习算法。

#### 2.3.1 网络结构

前馈神经网络（Feedforward Neural Network, FNN）由多个神经元分层排列，每层的神经元接收前一层的输出作为输入，经过线性变换和非线性激活函数后输出到下一层。信息单向流动，没有反馈连接。

对于一个两层的神经网络：

- **输入层**：接收原始特征 $\boldsymbol{x} \in \mathbb{R}^{D}$
- **隐藏层**：对输入进行线性变换后通过非线性激活函数
  $$\boldsymbol{z}^{(1)} = \boldsymbol{W}^{(1)}\boldsymbol{x} + \boldsymbol{b}^{(1)}, \quad \boldsymbol{a}^{(1)} = h(\boldsymbol{z}^{(1)})$$
- **输出层**：将隐藏层的表示映射到输出空间
  $$\boldsymbol{z}^{(2)} = \boldsymbol{W}^{(2)}\boldsymbol{a}^{(1)} + \boldsymbol{b}^{(2)}, \quad \boldsymbol{a}^{(2)} = \text{softmax}(\boldsymbol{z}^{(2)})$$

#### 2.3.2 激活函数

常用的激活函数有：

- **Sigmoid 函数**：$\sigma(x) = \frac{1}{1 + e^{-x}}$，输出范围为 $(0, 1)$，存在饱和区梯度消失问题
- **Tanh 函数**：$\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$，输出范围为 $(-1, 1)$，零中心化
- **ReLU 函数**：$\text{ReLU}(x) = \max(0, x)$，有效缓解梯度消失

#### 2.3.3 反向传播算法

反向传播（Backpropagation, BP）是训练神经网络的核心算法，其本质是**链式法则**的反复应用。算法分为两步：

**前向传播**：从输入层到输出层逐层计算，得到最终输出和损失值。

**反向传播**：从输出层到输入层反向计算损失对每层参数的梯度：

1. **输出层梯度**：对于 Softmax + 交叉熵的组合，梯度形式非常简洁
   $$\frac{\partial \mathcal{L}}{\partial \boldsymbol{z}^{(2)}} = \boldsymbol{a}^{(2)} - \boldsymbol{y}$$

2. **隐藏层梯度**：通过链式法则将误差从输出层传播回隐藏层
   $$\frac{\partial \mathcal{L}}{\partial \boldsymbol{z}^{(1)}} = \left( \frac{\partial \boldsymbol{a}^{(1)}}{\partial \boldsymbol{z}^{(1)}} \right)^T \cdot \left( \frac{\partial \boldsymbol{z}^{(2)}}{\partial \boldsymbol{a}^{(1)}} \right)^T \cdot \frac{\partial \mathcal{L}}{\partial \boldsymbol{z}^{(2)}}$$

具体展开如下表（分母布局，Sigmoid 激活）：

| 梯度项 | 形式 | 维度 |
|:---:|:---:|:---:|
| $\partial \mathcal{L} / \partial \boldsymbol{W}^{(2)}$ | $\frac{1}{N}(\boldsymbol{a}^{(2)} - \boldsymbol{y})\boldsymbol{a}^{(1)T}$ | $C \times H$ |
| $\partial \mathcal{L} / \partial \boldsymbol{b}^{(2)}$ | $\frac{1}{N}\sum(\boldsymbol{a}^{(2)} - \boldsymbol{y})$ | $C \times 1$ |
| $\partial \mathcal{L} / \partial \boldsymbol{W}^{(1)}$ | $\frac{1}{N}(\boldsymbol{\delta}^{(1)})\boldsymbol{x}^T$ | $H \times D$ |
| $\partial \mathcal{L} / \partial \boldsymbol{b}^{(1)}$ | $\frac{1}{N}\sum\boldsymbol{\delta}^{(1)}$ | $H \times 1$ |

其中 $\boldsymbol{\delta}^{(1)} = (\boldsymbol{W}^{(2)T}(\boldsymbol{a}^{(2)} - \boldsymbol{y})) \odot \boldsymbol{a}^{(1)} \odot (1 - \boldsymbol{a}^{(1)})$ 为隐藏层的误差信号，$H$ 为隐藏层神经元数量，$D$ 为输入维度，$C$ 为类别数。

## 四、实验内容

### 4.1 数据集介绍

使用 torchvision 提供的 **MNIST 手写数字数据集**：

- 图像大小：28×28 像素（灰度图，每个像素值 0-255）
- 输入维度：784（28×28 展平）
- 训练集：60,000 张
- 测试集：10,000 张
- 类别数：10（数字 0-9）

数据预处理：

| 步骤 | 操作 |
|:---|:---|
| 展平 | 28×28 → 784 维向量 |
| 归一化 | Min-Max 归一化至 [0, 1] 区间 |
| 划分 | 训练集 50,000 / 验证集 10,000（从训练集分出） |

### 4.2 网络结构

```
输入层 (784)  →    隐藏层 (128)    →    输出层 (10)
    X        W1(128×784)+b1    A1(Sigmoid)   W2(10×128)+b2    A2(Softmax)
```

| 组件 | 参数 |
|:---|:---|
| 输入层维度 | 784（28×28 展平） |
| 隐藏层神经元数 | 128 |
| 隐藏层激活函数 | Sigmoid |
| 输出层激活函数 | Softmax |
| 损失函数 | 交叉熵损失 |
| 参数初始化 | Xavier 初始化 |
| 优化算法 | Mini-batch 梯度下降 |
| 批大小 | 64 |
| 学习率 | 0.5 |
| 迭代轮数 | 100 |

### 4.3 算法实现流程

手写版实现（单个 batch 的处理流程）：

```
初始化参数 W1, b1, W2, b2 
对于每轮 epoch = 1, 2, ..., E:
    1. 打乱训练数据
    2. 将数据划分为大小为 batch_size 的 mini-batch
    对于每个 mini-batch:
        a. 前向传播:
           Z1 = W1 @ X_batch + b1      →  A1 = sigmoid(Z1)
           Z2 = W2 @ A1 + b2           →  A2 = softmax(Z2)
        
        b. 计算损失:
           L = -(1/m) * ΣΣ(Y ⊙ log(A2))
        
        c. 反向传播:
           dZ2 = A2 - Y
           dW2 = (1/m) * dZ2 @ A1.T
           db2 = (1/m) * ΣdZ2
           dA1 = W2.T @ dZ2
           dZ1 = dA1 ⊙ A1 ⊙ (1 - A1)
           dW1 = (1/m) * dZ1 @ X.T
           db1 = (1/m) * ΣdZ1
        
        d. 梯度下降更新:
           W2 ← W2 - lr * dW2
           b2 ← b2 - lr * db2
           W1 ← W1 - lr * dW1
           b1 ← b1 - lr * db1
    3. 记录本轮平均损失
    4. 在验证集上评估准确率
```

### 4.4 训练过程

两版模型均采用相同超参数：

- 网络结构：784 → 128（Sigmoid）→ 10（Softmax）
- 优化器：SGD（学习率 0.5）
- 批大小：64（每轮约 781 个 batch）
- 训练轮数：100

训练日志节选（手写版）：

```

Iter 100/100 | Loss: 0.0025 | Val Acc: 0.9772
```

训练日志节选（PyTorch 版）：


### 5.3 结果分析

#### 5.3.1 损失曲线分析

从训练曲线可以看到，两版模型的损失曲线呈现典型的**快速下降 → 缓慢收敛**模式：

- **Epoch 0-20（快速下降期）**：损失从初始值迅速降至约 0.03（PyTorch 版第 20 轮 0.0305）。此时网络参数从随机初始化快速调整，学习到最显著的判别特征（如数字的轮廓信息）。这个阶段验证准确率也从 ~90% 快速提升至 ~97.5%。

- **Epoch 20-60（精细调整期）**：损失从 0.0305 降至 0.0043，下降速度明显放缓。此时网络开始学习更细微的判别特征（如数字 3 与 5、8 与 9 的区分），验证准确率缓慢提升约 0.4%。

- **Epoch 60-100（接近饱和期）**：损失从 0.0043 降至 0.0019，下降极为平缓。模型已接近收敛，验证集准确率稳定在 97.8%-97.9% 之间，不再显著提升。

值得注意的是，整个训练过程中**损失曲线平滑下降，没有明显震荡**，说明学习率 0.5 的选择是合适的。如果学习率过大，损失曲线会出现剧烈波动甚至发散；如果过小，则收敛速度会明显变慢。

#### 5.3.2 验证准确率分析

验证集准确率的变化趋势与损失曲线高度吻合：

- 验证准确率从初始约 90% 迅速攀升至 97% 以上（前 20 轮），随后进入缓慢增长期
- 最终准确率稳定在 **97.7%（手写版）** 和 **97.9%（PyTorch 版）** 左右
- 验证准确率曲线**没有出现过拟合的典型特征**（即验证准确率先升后降），说明模型容量对于 MNIST 数据集是合适的

#### 5.3.3 训练集准确率 100% 的含义

两版模型在训练集上均达到 **100.00%** 准确率，这意味着：

1. **模型容量足够**：128 个隐藏神经元、约 101,760 个参数（784×128 + 128 + 128×10 + 10），足以记住 50,000 个训练样本的所有判别特征
2. **数据线性可分（在特征空间）**：经过 Sigmoid 非线性变换后，网络学到的 128 维隐藏层表示使得不同数字在这个特征空间中线性可分
3. **存在一定程度的过拟合风险**：但验证集 97.72%-97.86% 的准确率表明，过拟合程度并不严重，模型具有良好的泛化能力

#### 5.3.4 泛化性能分析

| 差距类型 | 手写版 | PyTorch 版 | 说明 |
|:---|:---:|:---:|:---|
| 训练集 - 验证集 | 2.28% | 2.14% | 模型在未见数据上略有下降，属于正常范围 |
| 验证集 - 测试集 | +0.23% | +0.17% | 测试集准确率略高于验证集，说明没有过拟合 |
| 训练集 - 测试集 | 2.05% | 1.97% | 整体泛化差距约 2%，对于简单两层网络而言表现良好 |

测试集准确率（97.94%-98.03%）略高于验证集准确率（97.72%-97.86%），这是一个有趣的观察。这可能是由于验证集是从训练集中划分出来的，其数据分布与训练集更接近，但验证集规模较小（10,000 张），存在一定的随机波动。

#### 5.3.5 手写版与 PyTorch 版对比分析

两版模型在完全相同的网络结构和超参数下训练，最终结果**高度一致**：

| 对比维度 | 手写版 | PyTorch 版 | 差异 |
|:---|:---:|:---:|:---:|
| 测试集准确率 | 97.95% | 98.03% | **0.08%** |
| 最终损失 | 0.0025 | 0.0019 | 0.0006 |
| 训练时间 | ~6.5 min | ~6 min | 接近 |

这 **0.08% 的微小差异** 并非手写梯度有误，而是由以下原因导致：

1. **随机打乱顺序不同**：两版的随机种子不同，导致每轮看到 mini-batch 的顺序不同，最终的收敛点也会略有差异
2. **浮点运算精度**：手写版使用 NumPy（float64），PyTorch 版默认使用 float32，精度差异在多次迭代后会积累微小误差
3. **数值稳定性实现细节**：Softmax 和交叉熵的数值稳定技巧略有不同

**结论**：0.08% 的差异在随机训练的正常波动范围内，完全可以忽略。这一结果充分验证了手写反向传播算法的正确性。

#### 5.3.6 超参数选择分析

| 超参数 | 选择理由 |
|:---|:---|
| **学习率 0.5** | 输入已归一化到 [0,1]，Xavier 初始化让权重≈0.04，梯度量级很小，0.5 恰好能快速收敛且不震荡 |
| **batch_size=64** | 经典小批量大小，在收敛速度和泛化能力之间取得良好平衡 |
| **隐藏层 128 神经元** | MNIST 有 10 个数字类别，每个数字需要学习不同的笔画模式，128 神经元为每类分配约 12-13 个特征检测器 |
| **Sigmoid 激活** | 两层网络 + Sigmoid 的配合不会产生严重的梯度消失问题，且 Sigmoid 的输出在 (0,1) 区间，与 Softmax 的概率输出相协调 |

## 六、结论

1. **成功实现**：从零实现了一个完整的两层神经网络（784 → 128 → 10），使用 Sigmoid 激活函数和 Mini-batch 梯度下降，在不依赖深度学习框架的情况下完成了 MNIST 手写数字识别任务。

2. **双重验证**：同时使用 PyTorch 自动求导实现了完全相同的网络结构，两版结果高度一致，验证了手写反向传播算法的正确性。

3. **良好性能**：两版模型在 MNIST 测试集上分别达到 **97.95%（手写版）** 和 **98.03%（PyTorch 版）** 的准确率，验证了该网络结构的有效性，且两者仅相差 0.08%，充分说明了手写梯度的正确性。
